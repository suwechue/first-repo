Small (16x16 recommended) icons for the resource bar at the top of the
screen. Drop PNGs with these exact filenames here to replace the emoji
placeholders:

  wood.png
  stone.png
  fiber.png
  food.png
  cookedfood.png

Missing files fall back to an emoji automatically — see
RES_ICON_FALLBACK in js/config.js if you want to change the fallback
emoji itself.
